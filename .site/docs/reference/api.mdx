# API Reference

This document provides a high-level overview of the core APIs exposed by the React Dart workspace packages.

## `package:react`

The core package defines the component tree and essential hooks. It is platform-agnostic and contains no browser dependencies.

### Core Types

- `abstract class ReactNode`: The base class for all elements in the React tree.
- `class Component<P>`: Represents a Dart component instance with `props`, `key`, and `children`.
- `class HostNode<P>`: Represents a native host element (like an HTML `div` or `span`).
- `class Text`: A text node.
- `class Fragment`: Groups children without adding an extra DOM node.

### Hooks

- `(T, StateSetter<T>) useState<T>(T initial)`: Returns a stateful value and a function to update it.
- `void useEffect(EffectCallback effect, [List<Object?>? deps])`: Accepts a function that contains imperative, possibly effectful code. Skips execution during SSR.
- `void useLayoutEffect(EffectCallback effect, [List<Object?>? deps])`: Similar to `useEffect`, but fires synchronously after all DOM mutations.

## `package:react_actions`

Handles server-client RPC communication.

### Annotations

- `@serverFunction`: Marks a top-level function as an RPC endpoint. The function must take `ServerFunctionContext` as its first argument and return a `Future`.
- `@serverData`: Marks a `final class` as a serializable data transfer object (DTO). The class must have exactly one public generative constructor with named parameters matching its final fields.

## `package:react_server`

Server-side execution utilities for SSR and Server Functions.

- `class ServerFunctionContext`: Passed to `@serverFunction`s. Provides access to DI via `get<T>()` and request metadata.
- `class SsrRenderer`: Manages a pool of JS workers for rendering React components to HTML strings. Use `SsrRenderer.start(manifestPath: ...)` to initialize.
- `class SsrResponse`: The returned data from an SSR render, containing `html` and `head` strings.

## `package:react_dom`

Browser-specific rendering and hydration.

- `void hydrateRoot(Element container, ReactNode initialChildren)`: Hydrates a server-rendered HTML document, making it interactive.
- `Root createRoot(Element container)`: Creates a React root for client-only rendering, bypassing SSR hydration.

## `package:react_testing`

Testing utilities.

- `class ReactTestHarness`: Orchestrates the testing build server.
  - `start(...)`: Initializes the harness.
  - `renderClient()`: Renders the component in a headless browser and returns a page controller.
  - `renderSsr()`: Returns the raw HTML string as rendered by the SSR worker.
