# Type system

React Dart represents UI as a portable, strongly typed `ReactNode` tree. Dart
component source is shared by browser compilation, Node SSR, and native tests.

## Nodes and children

The main node kinds are `Component`, `HostNode`, `ForeignComponent`,
`Text`, `Fragment`, and `Empty`. Runtime features add lazy, memoized,
forward-ref, context, suspense, portal, and error-boundary nodes.

Host nodes are created through typed factories:

```dart
div(
  id: 'profile',
  className: classNames('card', {'selected': selected}),
  style: css(padding: 16),
  children: [
    'Hello ',
    user.name,
    if (user.admin) strong(children: ['admin']),
  ],
)
```

`ReactChildren` accepts nested iterables, nodes, strings, numbers, booleans,
and null. The runtime normalizes them before rendering, so explicit `Text`
construction is optional.

## Component props

An authored component accepts exactly one named record:

```dart
import 'package:react_dom/react_dom.dart';

@reactComponent
ReactNode Avatar(({
  required String src,
  int? size,
  ReactChildren children,
}) props) {
  return figure(children: [
    img(src: props.src, width: props.size, height: props.size),
    ...props.children,
  ]);
}
```

Code generation preserves that record as the internal component contract and
emits an ergonomic callable factory:

```dart
Avatar(src: '/ada.png', size: 48, key: 'ada')
```

It also emits `Avatar.props()` for builder-style composition. Required props
are `late` builder fields and must be assigned before invocation.

## Host props and events

Generated HTML and SVG factories expose named Dart parameters for Web IDL and
React event props. Event callbacks use typed synthetic events and portable host
interfaces:

```dart
import 'package:react_web/web.dart' show HTMLInputElement;

input(
  value: query,
  onChange: (event) {
    final input = event.currentTarget as HTMLInputElement;
    setQuery(input.value);
  },
)
```

Use `additionalProps` for uncommon attributes and the
`dataAttributes(...)`/`aria(...)` helpers for structured custom
props.

## Styles

React's `style` prop is a property map, never a serialized CSS string.
`css(...)` builds that map and supports numeric values, CSS custom properties,
and additional properties.

```dart
div(style: css(maxWidth: 640, margin: '0 auto', opacity: 0.9))
```

## Foreign values

`foreignComponent` accepts `Map<String, Object?>` props. The React codec
registry converts supported primitives, iterables, maps, records, callbacks,
React nodes, and registered host values at the JavaScript boundary.

Do not wrap callbacks with legacy `allowInterop` helpers. Typed host/generated
callback parameters accept ordinary Dart closures. The generic
`foreignComponent` map requires an explicit `ReactCallback` descriptor because
it has no TypeScript signature to infer.

For a stable external API, generate typed bindings with `react ts bind` and
export those helpers from a wrapper package.
