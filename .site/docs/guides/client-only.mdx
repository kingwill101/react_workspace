# Client-only applications

The `client` starter builds a static React application without a Dart server or
Node SSR worker.

## Scaffold

```console
dart run react_tool:react init my_client_app --template client
cd my_client_app
dart pub get
```

Its `react.yaml` configures only the browser entrypoint and static output:

```yaml
client:
  entrypoint: web/client.dart
static: web
output: build/react
```

## Browser entrypoint

Mount an App factory into the empty HTML shell:

```dart
import 'package:my_client_app/.generated/app.react.dart';
import 'package:my_client_app/.generated/react_components.g.dart';
import 'package:react_dom/react_dom.dart';

void main() {
  initReact();
  registerReactComponents();
  mount(getRoot('app'), App(title: 'Client only'));
}
```

`getRoot` and `mount` avoid direct `dart:html` or `dart:js_interop` code in
the application entrypoint.

## Develop and build

```console
dart run react_tool:react serve --watch
dart run react_tool:react build --release
```

With no server entrypoint, `serve` starts the built-in static server.
`build/react/` contains the rewritten `index.html`, client JavaScript,
browser entry module, styles, static assets, and any foreign bundles.

Deploy that directory to static hosting. Client-side routers require a hosting
fallback that serves `index.html` for document paths.
