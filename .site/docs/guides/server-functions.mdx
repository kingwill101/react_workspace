# Server functions

Server functions are typed RPC contracts generated from Dart source. The
implementation runs on the Dart server; browser code calls a generated client
proxy through the configured `ServerFunctionClient`.

## Define the contract

```dart
import 'package:react_actions/react_actions.dart';
import 'package:react_server/react_server.dart';

@serverData
final class UserProfile {
  final String id;
  final String email;

  const UserProfile({required this.id, required this.email});
}

@serverFunction
Future<UserProfile> loadProfile(
  ServerFunctionContext context, {
  required String userId,
}) async {
  final principal = context.principal;
  // Authorize principal, then load durable data.
  return UserProfile(id: userId, email: 'user@example.com');
}
```

The context parameter is server-only. Generated browser proxies omit it.
Function parameters are named; generated codecs support primitives, lists,
maps, records, `DateTime`, `Uri`, and valid nested `@serverData` types.

## Generate

```console
dart run react_tool:react generate
```

For `lib/profile_actions.dart`, outputs under `lib/.generated/` include:

- `profile_actions.action.g.dart`: codecs and `ServerFunctionRef` values;
- `profile_actions.client.g.dart`: browser-callable `*Action` proxies;
- `profile_actions.registry.g.dart`: server dispatch registration;
- `server_actions.g.dart`: aggregate registry wiring.

## Call from a component

```dart
import 'package:my_app/.generated/profile_actions.client.g.dart';
import 'package:react_dom/react_dom.dart';

@reactComponent
ReactNode ProfileView(({String userId}) props) {
  final (profile, setProfile) = useState<UserProfile?>(null);
  final (error, setError) = useState<String?>(null);

  Future<void> load() async {
    try {
      setProfile(await loadProfileAction(userId: props.userId));
    } catch (failure) {
      setError(failure.toString());
    }
  }

  return section(children: [
    button(key: 'load', type: 'button', onClick: (_) => load(), children: [
      'Load profile',
    ]),
    if (profile case final value?)
      p(key: 'profile', children: [value.email]),
    if (error case final message?)
      p(key: 'error', children: [message]),
  ]);
}
```

The browser entrypoint installs `HttpServerFunctionClient` around the root
render with `runWithServerFunctionClient`.

## Register on the server

```dart
import 'package:my_app/.generated/server_actions.g.dart';
import 'package:react_server/react_server.dart';

final registry = ServerFunctionRegistry();
registerServerActions(registry: registry);
```

Pass that registry to `RoutedReactApplication` or `ReactServerApp`. The
adapter handles the versioned request/response envelope, content type, contract
hashes, body limits, authentication, cancellation, and structured failures.

Throw `ServerFunctionFailure` for an intentional public error code and status.
Unexpected exceptions are converted to safe remote failures; do not expose
stack traces or secrets to clients.

## Test

Use `ServerFunctionHarness` for direct dispatch and codec behavior. For the
HTTP envelope, compose the registry into the real server application and use
its `server_testing` adapter. This tests the production transport without a
fixed port or external browser automation.
