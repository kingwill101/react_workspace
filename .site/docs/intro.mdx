# Introduction to React Dart

Welcome to **React Dart**, a framework for building robust, scalable React applications entirely in Dart. By combining the power of the Dart language with the React ecosystem, React Dart offers a unique, type-safe development experience that bridges the gap between client and server.

## What is React Dart?

React Dart is a framework designed to build React interfaces using Dart, bringing full Server-Side Rendering (SSR), typed server functions, and a contract-based client/server communication model. It allows you to write components in Dart, which are then compiled and executed in the browser or rendered on the server.

### Core Philosophy

1. **Type Safety End-to-End**: Leverage Dart's strong type system across both the UI layer and the backend server logic.
2. **Seamless Server Integration**: With `@serverFunction`, call backend logic directly from your UI components without manually writing API endpoints or serialization logic.
3. **Interop without Tears**: Import and use any JavaScript/TypeScript React component effortlessly. React Dart handles the bundling and bridge generation.
4. **Zero-Configuration Build**: The `react_tool` CLI orchestrates Dart compilation, JS bundling (via esbuild or rolldown), and CSS/Sass compilation.

## Key Features

### 1. Server-Side Rendering (SSR)
React Dart supports out-of-the-box SSR. Your application renders to HTML on the server, sending a fully formed document to the client, which is then hydrated. This results in incredibly fast initial page loads and excellent SEO.

### 2. Typed Server Functions
Gone are the days of manual REST APIs for every small interaction. By simply annotating a Dart function with `@serverFunction`, React Dart automatically generates the necessary client proxies, cryptographic contract hashes, and secure serialization codecs.

```dart
@serverFunction
Future<bool> validateUser(ServerFunctionContext context, {required String username}) async {
  return await db.users.exists(username);
}
```

### 3. Automated Code Generation
React Dart embraces Dart's macro and builder ecosystem. The `react_codegen` package generates:
- Pure sealed Dart components (e.g., `Component` with keys and children).
- JavaScript wrapper extensions for seamless prop passing.
- Action codecs for server functions.

### 4. Foreign Component Support
Want to use `react-router-dom` or a complex date picker from npm? React Dart's `foreign:` configuration lets you register JavaScript/TypeScript components. The CLI bundles them, and you can generate typed Dart bindings to interact with them as if they were native Dart components.

### 5. First-class CSS and Sass
Support for CSS and Sass is built directly into the CLI. Simply define your styles in `react.yaml`. It also supports CSS Modules natively for any file ending in `.module.scss`, `.module.sass`, or `.module.css`.

## Ecosystem Packages

The React Dart workspace is composed of several specialized packages:

- **`react`**: The core package containing the portable `ReactNode` tree, `Component` definitions, and core hooks (`useState`, `useEffect`).
- **`react_dom`**: Handles DOM mounting, hydration, and browser-specific implementations.
- **`react_js`**: Provides the JavaScript bindings and exhaustive renderer switches.
- **`react_actions`**: Contains the `@serverFunction` and `@serverData` annotations for client-server RPC.
- **`react_codegen`**: The build_runner backend that generates `.react.dart` component files and `.react.g.dart` JS wrappers.
- **`react_tool`**: The CLI that orchestrates the entire build pipeline (`react build`, `react serve`).
- **`react_testing`**: Tools for executing headless browser testing and SSR validation.
