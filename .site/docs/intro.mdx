# React Dart

React Dart is a typed Dart component system that renders through React in the
browser and Node SSR while keeping server transports and JavaScript wrappers
modular.

## What it provides

- portable `ReactNode`, component, hook, context, ref, suspense, memo, lazy,
  and error-boundary contracts;
- generated HTML/SVG factories and Web API shapes shared by browser and SSR;
- browser mounting and hydration through `react_dom`;
- typed server functions with generated symmetric codecs;
- separate Routed and Shelf server integrations;
- npm wrapper descriptors and generated TypeScript bindings;
- Sass, CSS Modules, foreign bundles, and build manifests;
- native component, SSR, server-function, generator, and full-build harnesses.

## Component model

```dart
import 'package:react_dom/react_dom.dart';

@reactComponent
ReactNode Greeting(({String name}) props) {
  return h1(
    style: css(color: '#6d5dfc'),
    children: ['Hello, ${props.name}'],
  );
}
```

The authored function is portable. Code generation emits a callable factory and
browser/SSR bridges under `lib/.generated/`.

## Package boundaries

- `react`: portable model and runtime contracts;
- `react_web`: pinned generated Web surface and host factories;
- `react_dom`: recommended component entrypoint plus mount/hydrate;
- `react_js`: JavaScript renderer and React hook implementation;
- `react_actions`: browser-safe server-function protocol;
- `react_server`: transport-neutral registry and SSR primitives;
- `react_server_routed` / `react_server_shelf`: concrete HTTP integrations;
- `react_codegen`: Dart source generation;
- `react_tool`: scaffolding, generation, compilation, npm, and serving;
- `react_testing`: native test stack built on `server_testing`;
- `react_analysis` / `react_analyzer`: shared semantics and IDE diagnostics.

## Start

```console
dart run react_tool:react init my_app --template routed-minimal
cd my_app
dart pub get
dart run react_tool:react serve
```
